# ADR-001: Стек и архитектура

Статус: accepted · Дата: 2026-08-02 · Требования: см. PRD.md

## Контекст

Трекер тренировок на одного пользователя. Ключевые ограничения: iPhone без публикации в сторе, данные на сервере, вход через Google, использование в зале (мобильный, быстрые тапы), бюджет $0, нулевая нагрузка. Домен - чистый CRUD над своими данными, серверной логики нет.

## Решение

**PWA: Vite + React (SPA) → Vercel. Бэкенд: Supabase (Postgres + Auth + RLS), запросы с фронта напрямую, серверного кода ноль.**

- PWA ставится на главный экран iPhone и закрывает требование «без стора».
- Supabase даёт Google OAuth галочкой, авто-API над Postgres и приватность через RLS-политику `user_id = auth.uid()`. Барьер безопасности - сама база, клиенту доверять не нужно.
- Vercel - только раздача статики: git push → деплой, preview на ветку, HTTPS из коробки (обязателен для service worker).
- Расширение на v2 без смены архитектуры: LLM-фичи и интеграции - через Supabase Edge Functions (в фритире 500k вызовов/мес).

## Рассмотренные альтернативы

- **Нативный iOS** - отклонено: без стора только TestFlight с лимитом 90 дней.
- **Свой бэкенд (Node/Python + хостинг БД)** - отклонено: недели работы на auth и API без единой причины в требованиях. Оверинжиниринг.
- **Firebase** - рабочий вариант, отклонено: реляционная схема (шаблоны → сессии → подходы) ложится на Postgres лучше, чем на документы; плюс SQL-экспорт как страховка от лока.
- **Next.js** - отклонено: SSR не нужен (приложение за логином, SEO нет). SPA тупее - значит надёжнее.
- **Cloudflare Pages / Netlify** - равноценны Vercel, разница для кейса нулевая; Vercel выбран как дефолт с лучшим DX.

## Последствия

- (+) $0 на всё, запас фритиров x100 от потребности; время до первого деплоя - часы.
- (+) Один язык (TS) и одна кодовая база - фронт.
- (−) Вендор-лок на Supabase. Митигировано: под капотом обычный Postgres, `pg_dump` уносит всё.
- (−) Фритир паузит проект после 7 дней без запросов. Митигировано: cron-пинг (GitHub Actions) или кнопка resume за 30 сек.
- (−) Инварианты данных живут в базе (constraints, RLS), а не в коде - дисциплина миграций обязательна с первого дня.
- (−) iOS-пуши для PWA ограничены - осознанно вне скоупа (non-goals v1).
