# DESIGN.md - дизайн-система FitFit

Статус: accepted · Слайс: 6 (редизайн «kawaii»)
Референс: дашборд «RM: воронка к 750» (20.10.2026). Стиль: светлая кремовая пастель + немного котиков.

## Принципы

1. **Читаемость в зале важнее милоты.** Kawaii - акценты, а не функциональные элементы. Контраст текста - AA (4.5:1 для основного).
2. **Тап-таргеты >= 44px** - не обсуждается, стиль их не уменьшает.
3. Мягкость через радиусы, пастель и тени - не через тонкие рамки и острые углы.
4. Один экран - одна доминирующая пастель. Панели цветокодируют смысл, а не украшают.

## Типографика

- **Display (заголовки, цифры):** Rubik 700/800. Загрузка: Google Fonts, `display=swap`; fallback `system-ui`. В кириллице оба шрифта полные.
- **Body (текст, подписи):** Nunito 400-800.
- H1: 28px/800, H2-экрана: 22px/800, заголовок карточки: 17px/700, body 16px, подписи 13px/700.
- Цифры (веса, повторы) - `tabular-nums`.

## Форма и тени

- Радиусы: карточки 22px (`rounded-[22px]`), внутренние блоки 16px, кнопки 14px, пилюли 999px.
- Тень карточки: `0 1px 0 var(--color-line), 0 10px 24px -16px rgba(42,47,90,.35)`.
- Разделители между смысловыми блоками: `2px dashed var(--color-line-2)` (footer, «прошлый раз»).
- Карточка-обёртка: белая с padding 10px, внутри цветная панель с радиусом 16px (паттерн «паспарту» из референса) - для резюме и KPI.

## Компоненты

- **Кнопка главная** («+ подход», «Начать»): фон `accent`, белый текст, 800, радиус 14px, min-h 44-52px.
- **Кнопка вторичная**: белая, рамка 2px `line`, текст `ink-2`.
- **Кнопка-призрак** («Пропустить», «Выйти»): без фона, подчёркнутый текст `muted`.
- **Степпер веса/повторов**: белые кнопки 48px, рамка `line`, значение по центру Rubik 800.
- **Бейдж-пилюля**: 12.5px/800, padding 5×10px, пастельный фон + текст `ink-2`. Смыслы: план (lilac), выполнено (mint), пропуск (grey `#eceaf0`).
- **Строка подхода**: `paper` фон, радиус 12px, цифры monospace/tabular.
- **Пустое состояние**: котик + короткая фраза + подсказка, панель `sky`.

## Kawaii-правила

- Маскот: кот (SVG, `src/components/`), 3 позы: приветствие (логин, пустые состояния), довольный (резюме тренировки, закрытый день), спящий (загрузка). Рисуем простыми формами, пастель + `ink`, без анимаций в боевых экранах.
- Лапка (paw print): маркер выполненного подхода и «Готово».
- Котик никогда не: не кнопка, не внутри строки подхода, не увеличивает высоту боевых экранов.
- Эмодзи в тексте не используем - только SVG.

## Навигация

Нижнее меню: «Тренировка», «Дни», «Ещё» (слайс 8). Активный таб - `accent` + жирнее, с точкой-лапкой под надписью. Фон меню: `surface`/95 + blur, верхняя граница `line`.

## Анти-примеры

- Тёмная тема не поддерживается (color-scheme: light).
- Не красить карточки упражнений в разные пастели в одном списке - список монотонный, пастель только у статусов.
- Не ставить котиков на кнопки действий.
