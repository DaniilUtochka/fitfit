# DESIGN.md - дизайн-система FitFit

Статус: accepted · Слайс: 6 (редизайн «kawaii»)
Референс: дашборд «RM: воронка к 750» (20.10.2026). Стиль: светлая кремовая пастель + немного котиков.

## Принципы

1. **Читаемость в зале важнее милоты.** Kawaii - акценты, а не функциональные элементы. Контраст текста - AA (4.5:1 для основного).
2. **Тап-таргеты >= 44px** - не обсуждается, стиль их не уменьшает.
3. Мягкость через радиусы, пастель и тени - не через тонкие рамки и острые углы.
4. Один экран - одна доминирующая пастель. Панели цветокодируют смысл, а не украшают.

## Типографика

- **Display (заголовки, цифры):** Rubik 700/800. Загрузка: Google Fonts, `display=swap`; fallback `system-ui`. В кириллице оба шрифта полные.
- **Body (текст, подписи):** Nunito 400/600/700/800 (грузятся с Google Fonts).
- Заголовок экрана: 30px/800 (`text-3xl`), внутренние экраны 24px/800 (`text-2xl`), логин 36px/800 (`text-4xl`), заголовок карточки: 17px/700, body 16px, подписи 12px (`text-xs`).
- Цифры (веса, повторы) - `tabular-nums`.

## Форма и тени

- Радиусы: карточки 22px (`rounded-2xl`, переназначен через `--radius-2xl`), внутренние блоки 16px, кнопки/инпуты 14px (`rounded-xl`, `--radius-xl`), пилюли 999px.
- Тень карточки: `0 1px 0 var(--color-border), 0 10px 24px -16px rgba(42,47,90,.35)`.
- Разделители между смысловыми блоками: `2px dashed var(--color-line-2)` (footer, «прошлый раз»).
- Карточка-обёртка: белая с padding 10px, внутри цветная панель с радиусом 16px (паттерн «паспарту» из референса) - для резюме и KPI.

## Компоненты

- **Кнопка главная** («+ подход», «Начать»): фон `brand`, белый текст, 800, радиус 14px, min-h 44-52px.
- **Кнопка вторичная**: белая, рамка 2px `border`, текст `ink-2`.
- **Кнопка-призрак** («Пропустить», «Выйти»): без фона, подчёркнутый текст `muted`.
- **Степпер веса/повторов**: белые кнопки 48px, рамка `line`, значение по центру Rubik 800.
- **Бейдж-пилюля**: 12px/700-800 (`text-xs`), padding 4×10px, пастельный фон + текст `ink-2`. Смыслы: план (lilac), выполнено (mint), пропуск (grey `#eceaf0`).
- **Строка подхода**: `paper` фон, радиус 14px (`rounded-xl`), цифры monospace/tabular.
- **Липкая панель отдыха** (слайс 12): фон `butter`, радиус 2xl, прибита к низу активной тренировки (нижнего меню с слайса 14 нет). Внутри: отсчёт (округление вверх, Rubik 800, tabular-nums), кнопки «+30с» и «Пропустить» (призрачные). По нулях - бип через WebAudio (разблокируется жестом тапа «подход») и надпись «Отдых закончен»; панель остаётся до тапа. Панель - единственное исключение из «один экран - одна пастель»: butter здесь сигнал активного процесса, а не украшение.
- **Точки прогресса пейджера** (слайс 12): ряд точек в шапке активной тренировки + счётчик «N/M». Точка: текущий слайд `brand`, пройденные `success`, непройденные `border`; тапабельные, тап-таргет >= 44px. Внизу - «Назад/Далее» (кнопка-призрак).
- **Пустое состояние**: котик + короткая фраза + подсказка, панель `sky`.
- **Иконка приложения** (слайс 11): kawaii-кот (голова маскота) на фоне `lilac` (#ede4ff), тонкий контур `#d9cdb8` (line-2) для читаемости силуэта на фоне рабочего стола. Источник - `public/logo.svg`; maskable-варианты с safe-зоной, apple-touch-icon - full-bleed (без прозрачных краёв).
- **iOS-сплеш** (слайс 11): кремовый фон `#fff6e8` + кот по центру, 6 портретных + 6 ландшафтных размеров. Генерируются скриптом: `npm run generate:splash` (`scripts/generate-splash.mjs`), link'и с media-запросами в `index.html`.
- **Оффлайн-пилюля** (слайс 11): полоса «Нет сети - подход может не записаться» на фоне `butter`, под плавающим кружком профиля (слайс 14), `pointer-events-none` - не перекрывает тапы. Как липкая панель отдыха: butter здесь сигнал, а не украшение. Парная механика - мутации (архив дня, «Убрать» из дня, архив упражнения) показывают явную ошибку вместо тихого провала.
- **Герой-карточка прогресса** (слайс 13): карточка-паспарту с панелью `lilac` (информация про будущее, не butter - на статичном экране он бы соврал). Внутри: крупная цифра Rubik 800 tabular-nums (~28-44px), дисклеймер-сноска 12px muted в две строки прямо в карточке - тон «сноски умного друга», не плашка, и inline-раскрышка: вся строка min-h-44 через dashed-разделитель, тап раскрывает формулу/источник. Эталон - герой «+дни жизни» на экране «Прогресс». Сестринские паттерны того же слайса: парные факты-панели `sky` в одном паспарту, стрик на `mint` с лапкой, рекорды и «Про Паркинсон» - белые карточки без пастели и кота. (Слайс 15 убрал из героя кота-happy: постоянный кот экрана переехал на кнопку старта, см. «Каст котов».)

## Каст котов (слайс 15)

Семь персонажей — перерисованы по референсу пользователя (v2, генерация в Gemini с богатой детализацией): WebP с альфой ~500×490 в `src/components/cats/assets/`, вырезка фона — flood-fill по почти-белым пикселям от краёв + 1px эрозия и мягкая альфа (конвейер как в `scripts/extract-cats.py`). Анимация — целиком спрайтом через CSS-классы `.cat-*`; zzz и конфетти — SVG-оверлеи поверх (`CatArt`, `src/components/cats/`):

| Кот | Арт | Роли (постоянные и событийные) |
|---|---|---|
| Повязка (`band`) | белый, малиновая повязка, лапки сложены | логин, пустые состояния «соберём», резюме «всё выполнено», история «день закрыт» |
| Коврик (`mat`) | белый на мятном коврике, хвост вверх | утро на кнопке старта, возвращение после перерыва (>7 дней), пустые «Дни» |
| Лежебока (`loaf`) | розово-лиловый пластом, ленивый хвост | дефолт днём на кнопке старта, таймер отдыха |
| Соня (`sleepy`) | персиковый спит, zzz плывут | вечер/ночь на кнопке старта, все загрузки, пустая история |
| Гантелька (`dumbbell`) | сиреневый с гантелькой, язык наружу | пустой справочник, пустой «выбор дня», выглядывает из меню профиля |
| Выжатый (`wrecked`) | серый, полотенце, бутылка, Х-глаза | резюме неполного плана, кот на кнопке после свежей тренировки (<3 ч), ошибка прогресса |
| Праздник (`joy`) | мандарин, руки вверх, конфетти | резюме с рекордами, праздник обновления PWA (разово) |

Правила каста:

- **Один постоянный кот на экран.** Постоянный - живёт на экране всегда (кнопка старта). Событийные коты (резюме, обновление) поверх допустимы, но тоже по одному и не одновременно.
- **Слот кнопки старта** - единственный постоянный кот Прогресса: кот лежит на верхнем краю кнопки (`pointer-events-none`, тап-таргет не меняет). Настроение выбирает `pickCtaCat` (`src/lib/mascot.ts`): свежая тренировка → выжатый; перерыв >7 дней или утро → коврик; вечер/ночь → соня; иначе лежебока. Тесты - `src/lib/mascot.test.ts`.
- **Анимации** - CSS-классы `.cat-*` (см. `src/index.css`): idle-циклы (парение, раскачивание, дыхание, zzz) бесконечные и едва заметные; событийные (потягивание, прыжок, конфетти) играют 2–3 раза и замирают. `prefers-reduced-motion` отключает всё.
- **Боевой флоу**: коты только в панели отдыха (лежебока дышит → повязка «поехали») и в резюме. В строках подхода, степперах, ошибках мутаций и оффлайн-пилюле котов нет.
- **Личные рекорды** резюме считает `countPrs` (workout/logic.ts): плановое упражнение, чей максимум сегодня выше максимума прошлой сессии. Рекорды → праздник с конфетти и строкой «Личных рекордов: N», иначе всё выполнено → повязка, меньше плана → выжатый.
- **Обновление PWA**: перед релоадом `pwa.ts` ставит флаг, Прогресс один раз показывает праздник «FitFit обновился» (3.4 с).
- Dev-галерея котов и слотов: `/mascots`, только в dev-сервере (`src/components/cats/Gallery.tsx`).

## Kawaii-правила

- Маскот: каст из 7 котов — спрайты с референса пользователя (`CatArt name=…`), не самодельный SVG.
- Лапка (paw print): маркер выполненного подхода и «Готово».
- Котик никогда не: не кнопка (лежит на краю кнопки старта, но тап-таргет - сама кнопка), не внутри строки подхода, не увеличивает высоту боевых экранов, не больше одного постоянного на экран.
- Эмодзи в тексте не используем - только SVG.

## Навигация

Нижнего меню нет - слайс 14 убрал его (до этого было «Тренировка / Прогресс / Ещё», слайс 13). Навигация - два плавающих паттерна:

- **Плавающий профиль-кружок**: кнопка 44px (`size-11`) в правом верхнем углу по safe-area, фон `surface` + тень карточки, лапка `brand`, z-50. Тап раскрывает меню-выпадашку 280px (`rounded-2xl bg-surface` + тень карточки): email (truncate), ссылки «Прогресс / Тренировка / Дни / История / Справочник упражнений» (min-h 44px), разделитель dashed, «Выйти» (призрачная). Закрытие - тап мимо, повторный тап, любая навигация. Рендерится только внутри Layout - на логине его нет.
- **Правило перекрытия**: плавающие элементы не перекрывают тап-таргеты. Заголовок экрана с правой кнопкой получает `pr-14` - на активной тренировке «Завершить» не заезжает под кружок.
- **Фиксированная CTA к низу** («Начать тренировку» на Прогрессе): `fixed` к нижней кромке по safe-area, `bg-brand`, белый текст 800, min-h 56px, лапка; `pointer-events` только у самой кнопки. Контент экрана добирает нижний паддинг (~4.5rem + safe-area), чтобы CTA ничего не перекрывала. Тап ведёт в обычный флоу /workout - CTA не дублирует inline-приглашения, в пустом состоянии второй кнопки нет.

## Анти-примеры

- Тёмная тема не поддерживается (color-scheme: light).
- Не красить карточки упражнений в разные пастели в одном списке - список монотонный, пастель только у статусов.
- Не делать кота кнопкой и не ставить его внутрь тап-таргета: единственное исключение - кот лежит на краю кнопки старта, `pointer-events-none`.
- Не анимировать боевые экраны: в активной тренировке движутся только кот в панели отдыха и (разово) резюме.
