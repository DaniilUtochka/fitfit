Слайс 4

Тренировка v0

Старт выбором дня → тап = подход, сразу в базу → завершение сессии. Восстановление активной сессии при перезаходе.

Слайс 5

«Прошлый раз» рядом с каждым упражнением, ratchet: план двигается только вверх. Резюме при завершении, пропуск и внеплановый подход. Плюс vitest и первые тесты.

Поднял вес — в следующий раз приложение само предложило новый

Редизайн «kawaii»

Кремовая тема, пастельные панели, Rubik + Nunito, радиусы 22px, мягкие тени — и котики: SVG-кот и лапки на пустых состояниях. Дизайн-система в DESIGN.md.

В зале всё читается, тёмно-светлой каши нет
Слайс 7

Импорт программы

Программа PPL из Google-таблицы: ~15 упражнений, Push / Pull / Legs, веса из названий — нижняя граница диапазона в план. Гребной — «минуты» в заметке.

Три дня с полным планом — можно сразу стартовать
Слайс 8

Справочник уходит из нижнего меню: на тренировке он только мешал. Добавление в день работает из редактора как раньше.

Меню на тренировке: только нужное
Слайс 12

Фокус-режим тренировки

Пейджер: одно упражнение на экран, без прыжков. Таймер отдыха 90с с автостартом, «+30с», бип в конце. Отмена тренировки, пока сделано < 20% плана.

Весь цикл «тап → отдых → следующий подход» без скролла
Milestone 2

Обновления без боли

Деплой уходит, а телефон подолгу показывал старое: iOS держит PWA в памяти днями. Теперь новый service worker перезагружает страницу сам, проверка — при каждом возврате в приложение.

Открыл приложение → видишь свежую версию
Релиз · 1 ноя 2026

Коты v2: новый каст маскотов

Все 7 спрайтов перегенерированы в Gemini по старому референсу — те же персонажи, но с богатой детализацией: ~500px WebP с альфой вместо 155–232px. Коты на экранах стали +30–40% крупнее (пустые состояния 110→148px). Плюс полировка анимаций: pop-появление на пустых состояниях, параллакс по скроллу, wiggle по тапу на декоративных котах, haptic-отклик на событийных (vibrate, no-op на iOS). Скрипты вырезки фона — в scripts/extract-cats-v2.py, исходники — в scripts/cats-v2-source/. По правилу из CLAUDE.md эта ретроспектива теперь пополняется после каждого релиза.

Проверено с айфона: «круто, очень классные анимации»
Каст v2: те же коты, но в разрешении, которое не стыдно
