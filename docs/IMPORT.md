# Импорт программы (слайс 7)

Статус: выполнен 2026-10-29 · Скрипт: `scripts/import_program.sql` · Схема: DATA-MODEL.md

## Откуда данные

Google-таблица **«Программа_PPL_трекер_v2»** — 7-недельная программа PPL. URL таблицы в репо не хранится: для импорта использовался CSV-дамп. Колонки недель 1–7 при разборе проигнорированы — взята одна текущая версия плана; разбивка по дням Push/Pull/Legs согласована с пользователем.

## Как читать scripts/import_program.sql

Разовый DML-скрипт, **не миграция** (правило 1 CLAUDE.md соблюдено: схему не меняет). Выполнен 2026-10-29 в прод-базу Supabase через MCP supabase (`execute_sql`). Повторно запускать нельзя — вставки не идемпотентны (без `on conflict`), второй прогон упрётся в unique-констрейнты и надублит всё, что не под констрейнтом.

Структура скрипта:

1. **exercises** — 17 уникальных упражнений с фиксированными uuid (`3f8b1c2d-…-5f2a3b4c5d01…11`), вставка с явным user_id единственного пользователя. Совпадений с уже существующим справочником нет.
2. **exercise_muscle_groups** — связки с существующими id справочника muscle_groups, новых групп не создаём.
3. **template_exercises** — план по дням. Дни Push/Pull/Legs **переиспользованы** (существуют со слайса 3, к ним привязана история сессий), новые дни не создавались — скрипт джойнится к `day_templates` по имени. В Legs на момент импорта позиции 1–2 занимали старые тестовые позиции (брусья, тяга штанги), поэтому импорт шёл с 3; 29.10.2026 по решению пользователя тестовые позиции удалены (тот же путь, что кнопка «Убрать» в редакторе дня; история сессий их не ссылается), план Legs перенумерован с 1.

## Правила разбора

- **Веса** — нижняя граница диапазона из таблицы (12–14 кг → 12). Исходный диапазон сохранён в `note` упражнения («Диапазон веса в исходной таблице: …»).
- **Повторы** — нижняя граница диапазона: 3×8–12 → `sets_planned` 3, `reps_planned` 8.
- **Дедуп**: дубликаты упражнений между днями (махи, паллоф-пресс, гребной) — одно упражнение в справочнике, разные позиции плана в разных днях (unique `template_id + exercise_id` соблюдён).
- **Кардио-компромисс**: «Гребной тренажер» (10 мин) → 1×10, `is_bodyweight = true`, note «Кардио: 10 минут. Повторы здесь = минуты».
- **HALO и паллоф-пресс** — без веса, `is_bodyweight = true`.
- Имена очищены от весов, которые в таблице жили в названиях.

## Что осталось доделать руками

- **Тяга гантели одной рукой в наклоне** и **подъёмы на носки** — в таблице веса не было: `is_bodyweight = false`, `weight = NULL`. Задать вес руками после первой тренировки; ratchet по ним не сработает, пока `weight` пустой (нечего поднимать).
