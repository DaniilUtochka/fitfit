# Беклог: вертикальные слайсы

Статус: accepted · Требования: PRD.md · Схема: DATA-MODEL.md

Принцип нарезки: каждый слайс - работающий end-to-end кусок, задеплоенный и проверенный с айфона. Не «весь бэк, потом весь фронт». Definition of done для каждого: миграции применены, фича работает в проде, проверена с телефона, закоммичена.

Прикидка: один слайс = одна сессия вайб-кодинга. Слайсы 4-5 - возможно, по две.

## Слайс 0 - Ходячий скелет

Репо + Vite/React/TS + проект Supabase + первая миграция (пустая) + деплой на Vercel + PWA manifest с иконкой.
**Проверка:** открыл URL с айфона, добавил на главный экран, видишь заглушку. CLAUDE.md лежит в репо.

## Слайс 1 - Auth

Google OAuth через Supabase, долгоживущая сессия, роутинг «не залогинен → логин».
**Проверка:** вошёл с айфона, закрыл, открыл через день - всё ещё внутри. Чужой anon-запрос к таблицам получает пустоту (RLS работает).

## Слайс 2 - Справочник упражнений

CRUD упражнений: имя, основная + вспомогательные группы мышц (сид muscle_groups в миграции), флаг bodyweight, заметка, ссылка на видео, архив.
**Проверка:** завёл 5 своих упражнений с телефона, заархивировал одно - из списка ушло.

## Слайс 3 - Конструктор дней

Создание дня, добавление упражнений с планом (подходы x повторы x вес, для bodyweight - без веса), порядок (position), правка веса руками (деволоад-сценарий).
**Проверка:** собрал свой реальный Push-день целиком за < 5 минут.

## Слайс 4 - Тренировка v0 · **Milestone 1: гугл-док больше не нужен**

Старт тренировки выбором дня → список упражнений с планом → тап = подход по плану (insert в sets сразу) → завершение сессии. Восстановление активной сессии при перезаходе.
**Проверка:** провёл реальную тренировку в зале только с приложением.

## Слайс 5 - Тренировка v1: прогрессия

«Прошлый раз» рядом с каждым упражнением; смена рабочего веса в сессии + ratchet (write-back в план); точечная коррекция подхода; ratchet по повторам для bodyweight; резюме при завершении (тоннаж, выполнено из плана); пропуск и внеплановый подход.
**Проверка:** поднял вес на тренировке - следующая тренировка этого дня предложила новый вес сама.

## Слайс 6 - Редизайн «kawaii»

Светлая кремовая тема по референсу (дашборд «RM: воронка к 750»): пастельные панели, Rubik + Nunito, радиусы 22px, мягкие тени, пилюли-бейджи + немного котиков (SVG-кот, лапки на пустых состояниях и резюме). Дизайн-система: docs/DESIGN.md.
**Проверка:** с айфона в зале всё читается, тап-таргеты не сломались, темно-светлой каши нет.

## Слайс 7 - Импорт программы

Разовый импорт программы из Google-таблицы «Программа_PPL_трекер_v2»: ~15 уникальных упражнений (чистые имена, веса из названий - нижняя граница диапазона - в план), дни Push / Pull / Legs, гребной как 1×10 с заметкой «минуты». SQL лежит в scripts/import_program.sql, вставка с явным user_id.
**Проверка:** с айфона видны три дня с полным планом и весами, можно сразу стартовать тренировку.

## Слайс 8 - Таб «Ещё»

Справочник упражнений уходит из нижнего меню в таб «Ещё»: редактирую его редко, а на тренировке он только мешает. Добавление упражнений в день работает из редактора дня как раньше.
**Проверка:** в меню на тренировке только «Тренировка», «Дни», «Ещё»; справочник доступен с «Ещё».

## Слайс 9 - История · **выполнен 29.10.2026 · Milestone 2: MVP закрыт (все must из PRD)**

Список сессий по датам, детали сессии, последние N результатов по упражнению в дне.
**Проверка:** нашёл, что делал две недели назад, за < 10 секунд. Не начинаем, пока не закрыты 6-8.

## Слайс 10 - Расписание [should]

CRUD schedule (день недели → тип дня), «сегодня по расписанию: Push» на главном экране, старт тренировки в один тап оттуда.
**Проверка:** в тренировочный день приложение само предлагает нужный день.

## Слайс 11 - PWA-полировка · **выполнен 29.10.2026** [should]

Сплеш, иконки, поведение при потере сети (честная ошибка, не тихая потеря тапа).
**Проверка:** офлайн-тап не теряется молча, иконка на главном экране айфона выглядит прилично.

## Слайс 12 - Фокус-режим тренировки [29.10.2026, запрос пользователя]

Три вещи на одном экране:
1. **Отмена тренировки**: кнопка «Отменить» видна, пока выполнено < 20% плана (doneSets/plannedSets по computeSummary). Подтверждение «подходы удалятся». Механика: DELETE сессии, sets каскадом (RLS delete-own уже есть). Ratchet-подъём плана от отменённой сессии не откатываем.
2. **Пейджер**: одно упражнение на экран вместо длинного скролла. Точки прогресса «3/7» в шапке (тапабельные), стрелки «Назад/Далее» внизу. Внеплановые упражнения - слайды после плановых.
3. **Таймер отдыха**: после тапа «подход» автостарт 90с (дефолт, без настроек в v1). Липкая панель внизу: отсчёт, «+30с», «пропустить». Живёт на уровне тренировки - не сбрасывается при переключении упражнения. По окончании - звук (вибрации на iOS PWA нет).

**Проверка:** в зале весь подход-цикл (тап - отдых - следующий подход - следующее упражнение) без скролла и прыжков; отменённая тренировка не появляется в истории сессий.

## Слайс 13 - Прогресс · **выполнен 29.10.2026** [29.10.2026, запрос пользователя]

Экран «Прогресс» в нижнем меню (Тренировка / **Прогресс** / Ещё; «Дни» переезжают в «Ещё»): мотивирующие цифры — герой «+дни жизни» (игривая экстраполяция Momma 2022 с дисклеймером и раскрышкой формулы), тоннаж/время в зале, тренировки + стрик, бары тоннажа по 8 неделям, разбивка по группам, рекорды, честная карточка «Про Паркинсон» (без выдуманных процентов). Всё считается на клиенте из существующих таблиц, миграций нет.
Спека: docs/PROGRESS.md (исследование и формулы) + docs/PROGRESS-UX.md (мокапы, ответы О1-О7, состояния).
**Проверка:** с айфона видно живые цифры по реальным тренировкам; первый экран помещается в 390×844 без скролла.

## Слайс 14 - Прогресс - главный экран, навигация в «Профиль» · **выполнен 29.10.2026** [29.10.2026, запрос пользователя]

Два изменения одной рестрактуры:
1. **Прогресс - главный экран**: «/» редиректит на /progress. На экране Прогресса - большая кнопка «Начать тренировку» (fixed к низу по safe-area, bg-brand, лапка, min-h 56px): тап → /workout (там обычный флоу: выбор дня или активная сессия). Inline-CTA из пустого состояния убрана - большая кнопка не дублируется.
2. **Нижнее меню удаляется полностью**. Вместо него - плавающий кружок профиля справа сверху (Paw на bg-surface, 44px, safe-area, z-50; только внутри Layout - на логине нет). Тап раскрывает панель 280px: email, «Выйти», ссылки «Прогресс / Тренировка / Дни / История / Справочник упражнений» (всё содержимое «Ещё» переезжает сюда; роут /more и экран MoreScreen удалены). Закрытие панели: тап мимо, повторный тап, любая навигация. Старая шапка с email/«Выйти» убирается. Оффлайн-пилюля переехала - теперь под кружком профиля. Плавающие элементы не перекрывают тап-таргеты: строке заголовка активной тренировки добавлен pr-14, чтобы «Завершить» не оказалась под кружком; «← Ещё» в истории заменено на «← Прогресс».

**Проверка:** с айфона: открыл приложение - сразу Прогресс с кнопкой старта; нижнего меню нет, профиль в углу, из него доходят до любого экрана; на активной тренировке кружок не мешает.
